# 🌍 Mundo 1 — Fundamentos do Python

Base essencial da linguagem **Python**, com foco nos **primeiros comandos**, **lógica inicial** e na **compreensão do funcionamento da linguagem**.

Este mundo foi desenvolvido para **iniciantes absolutos** e também para quem deseja **revisar os fundamentos do Python** de forma prática e organizada.

Todos os conteúdos possuem **exemplos executáveis em arquivos `.py`**, permitindo aprender diretamente pelo código.

---

## 📚 Conteúdos Abordados

### 🧩 Aula 01 — Primeiros Comandos

- Função `print()`
- Strings e uso de aspas simples e duplas
- Diferença entre texto e números
- Operações básicas
- Variáveis
- Entrada de dados com `input()`
- Comentários no código (`#`)

📄 **Arquivo:** `Aula1_PrimeirosComandos.py`
